## Ideia do Projeto

Aplicação em GoLang para processamento paralelo de ficheiros de texto utilizando programação concorrente.

O sistema permite:

- Ler múltiplos ficheiros simultaneamente  
- Contar palavras, linhas e caracteres  
- Processar ficheiros com vários workers  
- Comparar execução sequencial vs paralela  
- Mostrar estatísticas de performance  

---

## Tecnologias Utilizadas

- GoLang  
- Goroutines  
- Channels  
- WaitGroups  
- Mutex  
- Worker Pools  

---

## Conceitos Demonstrados

- Programação concorrente  
- Paralelismo  
- Comunicação entre goroutines  
- Sincronização de tarefas  
- Comparação de performance
